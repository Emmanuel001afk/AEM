## Permanent release route

Open https://github.com/Emmanuel001afk/AEM/releases/latest after a successful published main build. Only successful main builds passing runtime and downloaded-asset checksum verification become public releases. PR artifacts are not permanent releases.

- **Android:** `app-release.apk`. Install on Android; retain the existing app to preserve data. Android asks for installation permission. Updates must use the same signing certificate.
- **Windows recommended:** `AEM-Store-<version>-Setup-x64.exe`. Download and double-click this file directly. It installs AEM Store, Start Menu and desktop shortcuts and an uninstaller. Do not open it using WinRAR. Run a newer Setup over the existing installation to upgrade. App data is retained by default during uninstall.
- **Windows without installation:** `AEM-Store-<version>-Portable-x64.exe`. Double-click to run; it is not the Setup installer and does not register shortcuts or uninstall entries.
- **All platforms bundle:** `AEM-Store-<version>-Complete.zip`. Extract, then run the appropriate file above. This is not itself an installer.
- **Source code (zip/tar.gz)** generated by GitHub is for developers. It is not an installed Windows application.

`SHA256SUMS.txt` records the hashes of APK and EXEs. On Windows use `Get-FileHash -Algorithm SHA256 <file>`; on Linux use `sha256sum -c SHA256SUMS.txt` with all three files present. Hashes establish transfer integrity, not publisher trust. Windows executables are currently unsigned (no code-signing certificate configured); PE validation and resource icons do not make them Authenticode signed.

Android and Windows share a release name; Android's monotonically increasing version code is separate from Windows semantic version. `release.json` records the exact source revision. Actions artifacts are temporary CI downloads, often ZIP-wrapped by GitHub, not permanent release links.

The Android Supabase catalog publisher remains a separate downstream ingestion step. The GitHub release route includes both Windows files; Supabase APK ingestion does not imply Windows catalog ingestion or automatic Windows updates.
